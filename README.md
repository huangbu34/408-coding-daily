## 为什么有这个仓库

- 408 数据结构（45 分）本身就是编程能力的地基，刷题和备考是同一件事的两种说法
- 复试面试时，拿出连续一年的 commit 记录，比口头说"我编程还行"有说服力得多
- 一年后这些就是你自己写的复习资料

## 目录约定

``` 
leetcode/          # LeetCode 每日一题，文件命名：0001-two-sum.md（含代码 + 思路）
408-algorithms/    # 手写实现的 408 算法：链表、栈、队列、二叉树、排序、图
notes/             # 408 知识点与错题笔记，按 DS / 计组 / OS / 计网 分类
projects/          # 暑假项目：shell / HTTP 服务器 / mini KV / CSAPP Lab（四选一）
```

## 每日模板

每天提交的 commit message 建议这样写：

``` 
git commit -m "day 1: 单链表逆序（含递归与迭代两种写法）"
git commit -m "day 2: 408-DS 栈的应用：括号匹配 + 笔记"
```

## 记录规则

1. **宁可少不可断**：哪怕只提交一行笔记，也不要让当天空着
2. **不许空 commit**：不要为了绿点用空提交刷记录，老师点进去一看全是空白，反而减分
3. **代码必须有注释**：思路写进注释里，这是给一年后的自己看的
4. **做不出就看题解**，但看完要自己再形成一遍思路再提交
